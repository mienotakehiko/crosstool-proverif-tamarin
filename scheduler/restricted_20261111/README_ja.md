## 未完・保証しないこと

**完全なProVerif symbolic semanticsとTamarinの対応定理は未完。** 今回閉じたのは明示定義した限定遷移系間の有限観測列補題であり、その遷移系への全言語意味論からのadequacyは別途必要。

`fresh=[]` は現行両printerが `fresh[0]` を使うため不可。初期identityとprivate state channelは残し、更新中のfresh生成だけを除外した。単一threadも生成コードに強制されず、初期化を1回に制限した実行集合の話である。実ツールの到達チェックは元の複数初期化可能な生成物に対して行い、この制限を機械証明したものではない。

複数thread、初期化tableとの交錯、一般入力束縛、fresh名の全意味論、responder、leak、複製状態、Horn抽象、U全般、Rollback、性質式変換、最大実行・公平性・生存性は未証明。既存LM-OTS/LMSモデルは限定fragment外であり、成績を引き上げない。

現行定理節は既に「reviewed process-to-rule simulation」を仮定している。その仮定を使って対応を証明しても目標を仮定に残す。今回の補題はその仮定なしで局所遷移を証明するが、全体の未実証仮定は削除しない。LaTeXは**追加挿入用**であり、既存原稿への自動適用はしない。
