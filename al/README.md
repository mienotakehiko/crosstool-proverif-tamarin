# Achievement Level assignment

The release records the [0.1.0 implementation](../cimc/v0.1.0/cimc/al_assign.py), the recovered [0.1.1 assignment](../cimc/v0.1.1/cimc/al_assign.py) and [0.1.2 assignment](../cimc/v0.1.2/cimc/al_assign.py). The 0.1.2 [37-assertion test](../cimc/v0.1.2/tests/test_al.py) checks the assignment rules, including direction and provenance of a diagnosis. The [archived result](../cimc/v0.1.2/audit_0_1_2/al_37.log) records the original test pass. Standalone execution uses `python3 -B cimc/v0.1.2/tests/test_al.py` from the repository root.
